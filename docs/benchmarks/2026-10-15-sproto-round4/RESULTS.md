# TS Sproto 零头展开计数验收

实施前已将第三轮提交为 `72fc11a`，工作树当时干净，未推送。本轮只修改 TS 零块解包及相关验证；数值 Pack 的候选均未合入，没有更改 Go、公开 API、官方 wire 或资源额度。新修改留在工作树审查。

## 实现

零 mask 连续出现时，先确认总共四个零头，再按四字节展开计数；不足四个的尾部继续逐字节处理。每个零头仍扩展为八个零字节，保留现有总尺寸检查与有界前缀填零。没有新增缓冲、查表、缓存状态或第三方依赖；既有 16 KiB/实例保留上限和公开字节独占不变。

原生大块比较虽在纯零输入更快，但会拖慢重复短零串；混合展开与原生比较的方案也存在短段回退。因此最终只保留十行生产改动的展开计数。

## 测量口径

Node v23.11.0 / V8 12.9.202.28-node.14，Apple M2，darwin/arm64；2026-10-15T09:45:11.275Z → 2026-10-15T09:47:37.590Z。loadavg [4.32861328125, 4.6787109375, 4.685546875] → [5.5478515625, 4.9482421875, 4.78759765625]。共 222 项、每项五轮、1110 个计时样本；另行采集 CPU profile。

所有时间均为 µs/op，中位数；负百分比表示新实现耗时减少。修改前后 SP 与 PB 控制项在同一进程交错、反转顺序采样，每项热身至少约 50 ms、每轮约 100 ms。原生解码使用热缓冲，不包括外层安全预检、网络或 MAC。历史正式基线保持不变，不与本次样本混合。

Echo 文本在准备期只构造一次，PB 和两个 SP 版本共享输入，详情见下节。新增 17 种形态，当前共 46 种公开解包形态：原有 ASCII/零块/稀疏数据和 FF 前缀，加上重复 2–257 个零 word 后接非零 word，以及零前缀后接 ASCII。热身输入谱再次扩大，跨轮绝对值不能拼接算作优化收益。

## Echo 输入表示修正

初次完整采样中，SP 编码源码逐字节相同，但 4 KiB Echo 编码出现数倍差距。沿同一热身流程采集 profile，差距集中在 Buffer.byteLength 和 UTF-8 write；V8 DebugPrint 观察到 before 的文本为 SEQ_ONE_BYTE_STRING_TYPE、after 为 CONS_ONE_BYTE_STRING_TYPE。原脚本在每个版本中分别 repeat，字符串值相同却未控制内部表示。

现已改为共享一次构造的 Echo 输入，再重新完整采样。该修正只影响基准准备，未改生产编码器；早期非共享输入的 Echo 编码百分比需谨慎解读，不改写历史数据。代表性 body 原先已共享输入。探针摘要与非共享样本片段见 [input-context.json](input-context.json)，V8 调试选项只用于排查，正常基准不需要。

## 未保留的尝试

以下为开发期同进程五轮专项，输入与计时范围分别固定，只解释撤回理由，不与最终完整样本混合。完整候选源码和中间样本在忽略的 tmp/sproto-round4/。

| 候选 | 观察 | 取舍 |
| --- | --- | --- |
| Pack 八字节无分支写出 | 大型游戏/整数数组独立 Pack 约慢 17% / 21% | 撤回 |
| Pack 先 mask/count 再写有效字节 | 大型游戏/整数数组独立 Pack 约慢 36% / 30% | 撤回 |
| Pack 双字节查表 | 大型游戏/整数数组独立 Pack 约慢 18% / 20%，另需 256 KiB 表 | 撤回 |
| Pack 裁剪状态更新 | 仅约几个百分点收益，涉及现有容量保护路径 | 不扩大改动 |
| Unpack 直接原生比较长零块 | 纯零输入快，但重复 9–33 个零 word 可慢一倍以上 | 撤回 |
| 确认长段后混合原生比较 | 纯零输入仍快，部分短串仍回退超过 10%，控制分支也增加 | 不采用 |

最终选择四头展开而非为纯零包保留最佳数字。它继续使用 Sproto 原有布局，没有额外编码或改变 padding。

## 复现

按 [第三轮复现方式](../2026-10-15-sproto-round3/RESULTS.md#复现) 从提交构建基线模块，将源码提交改为 `72fc11a`；构建当前 TS 后顺序执行：

```sh
node examples/websocket-gate/scripts/benchmark-sproto-api.mjs tmp/protocol-sproto-round4 /absolute/baseline/sproto.mjs
GOFLAGS=-modfile=/private/tmp/gsr-next-codec.mod npm --prefix examples/websocket-gate run test:sproto:integration
SPROTO_ORACLE_DIR=/absolute/official-sproto python3 examples/websocket-gate/scripts/benchmark-oracle.py --correctness
```

不提交本地 replace，不同时进行计时、测试和 profile。
