# 递减预算：同源函数clone控制

2026-10-22。前轮报告已提交GSR `0dc46d8`，未推送。基线gosproto仍为 `92a155a`。递减预算候选与前轮pack.go逐字/SHA一致，**保留候选和原始小收益，暂不应用生产**。本轮未重复实现或择优改候选。

## 为什么增加clone

self让A/B调用同一个函数，可以观察调度、GC等波动，但不能覆盖“函数源码相同、地址不同”的执行上下文。此次在一个冻结二进制内同时放入原预检、只改名的原预检clone、递减预算预检，以及各自公开DecodePacked调用链。克隆函数仅在隔离实验库，不进入产品API。

先self，再clone1、候选pass1/pass2，最后clone2；每种模式四个消息，ABBA/BAAB交错。每次调用都新建结果，来源与预算相同；不从候选比值扣除self或clone，不把不同二进制的历史比例相乘。

[validation.json](validation.json)核对：两份原预检函数体只差声明名；两个公开基线调用链只差函数名/对应callee；原预检与clone助记符序列相同，各420条，公开包装各40条，六个相关函数的链接地址全部不同。这里证明的是源码及助记符形态相同，不冒称带地址/重定位的机器字节完全一致，也不能据此指定CPU cache或分支预测为唯一原因。

## 全部结果

Apple M2、Go1.24.13、GOMAXPROCS1/GOGC100。各格为中位/累计耗时变化；负值为B快。self与clone1/clone2均为原算法对照，pass1/pass2才是递减预算候选：

| 用例 | self | clone1 | pass1 | pass2 | clone2 |
| --- | ---: | ---: | ---: | ---: | ---: |
| int32_edges/public | -0.68% / +1.00% | -3.48% / -1.70% | +0.67% / +1.57% | -0.59% / -0.79% | +0.77% / -0.86% |
| game_large/public | -1.82% / -2.32% | +2.51% / +4.83% | +0.06% / +1.84% | -0.72% / +0.11% | +1.51% / +0.85% |
| addressbook/public | -2.03% / -1.89% | +0.15% / -0.27% | +0.10% / +1.47% | -0.20% / -2.55% | -1.65% / -2.86% |
| echo_ascii4k/public | -0.01% / -1.08% | -0.17% / -0.23% | +1.91% / +2.25% | +1.01% / -1.35% | +2.83% / +2.19% |

大型消息clone两遍中位慢2.51%/1.51%；整数clone从快3.48%变为慢0.77%。这说明在当前测量条件下，相同算法的独立函数也有可见差异，不能把所有小幅差值都归因于候选算法。

候选整数公开入口+0.67%/−0.59%，大型公开入口+0.06%/−0.72%，本轮没有重复确认此前大型−1.53%/−1.71%的收益；大型累计两轮都略慢。AddressBook近乎持平且累计方向不同，ASCII中位两遍偏慢。不能把旧样本删掉，也不能把clone的代价扣除后声称候选“校正后获益”。

这不是证明候选绝对无收益，更不是新的固定百分比门槛。此前整数纯Unpack及大型公开入口的小收益继续保留在前轮报告，但现有证据不足以把它作为生产提速实施。没有PB/TS新排名，也不据此推翻此前幅度更大且独立验证过的优化。

## 测量和验证范围

共20进程、1920块、200批校准；最终pilot均达到下限。时间块最小/中位/最大47.461/60.453/153.100ms，无块低于40ms。所有GC、分配、暂停和长尾保留，逐块比例及校准决策复算通过。达到时长下限不等于无系统波动或差异具备统计显著性。

26条主流程命令均成功，包括候选对原函数的native race/checkptr差分、共享wire fixture、编译及20进程。clone通过源码身份和链接符号核对建立对照，不额外制造一套重复行为夹具。候选pack.go与上轮已通过purego race/checkptr及官方C/Lua完整库的快照一致；本轮没有重复跑这些较完整验证，也不冒称它们是新执行的。

Go+汇编及harness Go源码和二进制哈希在测量前固定、结束后核对一致。JSON夹具和外部生成输入另提供事后SHA，明确不冒充测量前冻结，见 [inputs-observed-after.json](inputs-observed-after.json)。前轮与本轮数据各自绑定自己的二进制，加入clone后布局会改变，因此本轮仅补证据，不回填前轮结果。

复现：`python3 docs/benchmarks/2026-10-22-gosproto-budget-clone/run.py <新输出目录>`；然后运行本目录analyze.py/check-calibration.py，最后validate.py核对源码、符号和机器码形态。plan在计时前已写入，候选与两个clone同时编入，不能事后只给某个模式换二进制。
